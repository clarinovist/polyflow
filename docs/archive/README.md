## Penempatan arsip berikutnya

- Pindahkan hanya dokumen yang sudah jelas bersifat historis; tambahkan konteks
  waktu dan tautan panduan pengganti bila tersedia.
- Perbarui referensi ke path lama. Jangan mengarsipkan panduan yang masih aktif
  hanya karena tanggalnya lama.
- Simpan plan rutin, data tenant, screenshot berisi data, dan detail produksi di
  lokasi lokal sesuai kebijakan root, bukan di arsip tracked ini.
- Skrip historis berada di [scripts/archive/](../../scripts/archive/README.md),
  bukan dicampur dengan arsip dokumentasi. Jangan menjalankannya ulang.
