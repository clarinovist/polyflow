# Services Layer

## Purpose
Business logic layer. Actions are thin wrappers; all domain logic belongs here.

## Structure

```
services/
├── accounting/      # Chart of accounts, journals, periods, reports
├── analytics/       # Cross-domain analytics
├── auth/            # API key management
├── core/            # Notifications
├── dashboard/       # Executive stats
├── finance/         # Invoices, payments, reconciliation, auto-journal
├── hrd/             # Payroll, attendance, piece rates
├── inventory/       # Stock, movements, reservations, opname
├── maklon/          # Toll manufacturing
├── printing/        # ESC/P receipt generation
├── production/      # BOM, orders, execution, materials, MRP
├── purchasing/      # PO, receipts, invoices, returns
├── sales/           # Orders, quotations, fulfillment, returns
└── settings/        # App settings
```

## Patterns

### Service Structure
```typescript
export class MyService {
  static async doSomething(data: Input): Promise<Output> {
    // Use prisma for DB operations
    // Use transactions for multi-step operations
    // Throw BusinessRuleError for business rule violations
    // Throw NotFoundError for missing entities
  }
}
```

### Transaction Pattern
```typescript
await prisma.$transaction(async (tx) => {
  // All operations in single transaction
  // If any fails, all rollback
});
```

### Error Handling
- `BusinessRuleError` — Business rule violation (e.g., insufficient stock)
- `ValidationError` — Input validation failure
- `NotFoundError` — Entity not found
- `AuthorizationError` — Permission denied

### Auto-Journal Pattern
Financial transactions automatically generate journal entries:
- Sales invoice → Revenue + Receivable journal
- Purchase invoice → Expense + Payable journal
- Payment → Cash/Bank journal
See `finance/auto-journal-service.ts`

## Testing
Each service directory has `__tests__/` with unit tests.
Run: `npx vitest run src/services/`

## Gotchas

| Issue | Solution |
|-------|----------|
| Transaction timeout | Default 5s — increase for large batches |
| N+1 queries | Use Prisma `include` or `select` |
| Stale data after mutation | Call `revalidatePath()` in action layer |
| Auto-journal duplication | Check `isAutoGenerated` before creating |
| Tenant isolation | All queries must go through `withTenant()` |
